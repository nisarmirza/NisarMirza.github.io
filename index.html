Featured Project

Howling Abyss

A single-player third-person action RPG built from first principles on Unreal Engine 4's Gameplay Ability System — five distinct abilities, a combo melee system, behaviour-tree AI, and a fully data-driven, UI-bound attribute pipeline.

Unreal Engine 4 C++ & Blueprint Gameplay Programmer GAS Behaviour Tree AI UMG

You play as Shinbi, a warrior who has lost her powers and must reclaim them by carving through monsters down a single lane toward the nexus. The pitch fuses the ability fluidity of League of Legends and Spellbreak with the melee weight of The Witcher 3.

Every mechanic was engineered to be data-driven and scalable: abilities derive from a shared Gameplay Ability hierarchy, cost & cooldown live in Gameplay Effects, VFX rides on Gameplay Cues, and melee damage scales from a curve table so balancing happens in a spreadsheet — not in code.

I authored a full GDD & Technical Design Document — use-case analysis, functional/non-functional requirements, UML activity & class diagrams, and a level decomposition — then implemented the vertical slice and shipped a technical post-mortem.

ABILITY SYSTEM

5 Gameplay Abilities

Laser (DoT + push), Dash (impulse evade), Ground Blast (two-phase decal targeting + launch), Fire Blast (pull → push + burn cue), and Health Regen — each a GA subclass sharing one cost/cooldown base.

ATTRIBUTES

C++ Attribute Set

Health / Mana / Strength modelled as FGameplayAttribute with change delegates broadcasting straight into the UMG HUD for live bars, cost deduction and cooldown clocks.

COMBAT

Curve-Table Melee Combo

Three-hit combo via switch-on-int with montage slots; damage scales ×2 per hit from a Data Curve Table. Resets on timer, on ability cast, or on taking a hit.

ANIMATION

Layered Anim Blueprint

8×8 blend spaces, Layer Blend Per Bone splitting upper/lower body so melee montages never override locomotion, and AnimNotifyState-gated sword collision for frame-accurate hits.

C++ INTEROP

Exposed Spec Handle

The projectile sword needed FGameplayEffectSpecHandle at spawn — not exposed to Blueprint — so I wrote C++ to surface it via ExposeOnSpawn and apply GE spec to target.

AI

Three-Tier Behaviour Trees

Basic chasers, patrol-and-search minions, and a boss with aggressive regen, knockback and projectiles — plus burning AI that flees to water puddles to strip the fire tag.

AttributeSetBase.cpp
// Broadcast attribute changes from GAS into the UMG HUD
void UAttributeSetBase::PostGameplayEffectExecute(const FGameplayEffectModCallbackData& Data)
{
    Super::PostGameplayEffectExecute(Data);

    if (Data.EvaluatedData.Attribute == GetHealthAttribute())
    {
        float NewHealth = FMath::Clamp(GetHealth(), 0.f, GetMaxHealth());
        SetHealth(NewHealth);
        // delegate → player controller → main HUD
        OnHealthChanged.Broadcast(NewHealth, GetMaxHealth());

        if (NewHealth <= 0.f)
            OnAvatarDied.Broadcast();
    }
    else if (Data.EvaluatedData.Attribute == GetManaAttribute())
        OnManaChanged.Broadcast(GetMana(), GetMaxMana());
}
GA_Base.h — acquiring abilities
// Replace hard-coded slot assignment with a typed,
// range-based loop the Blueprint UI can call.
UFUNCTION(BlueprintCallable, Category = "Abilities")
void AcquireAbilities(TArray<TSubclassOf<UGameplayAbility>> Abilities);

void AAbilitySystemCharacter::AcquireAbilities(
        TArray<TSubclassOf<UGameplayAbility>> Abilities)
{
    for (TSubclassOf<UGameplayAbility> Ability : Abilities)
    {
        if (UMainGameplayAbility* GA =
                Cast<UMainGameplayAbility>(Ability.GetDefaultObject()))
        {
            AbilitySystemComp->GiveAbility(FGameplayAbilitySpec(Ability));
            AddAbilityToUI(GA);   // cooldown, cost, icon
        }
    }
}
Engineering Post-Mortem · Bugs Resolved
01
Double-damage dash overlapFoot & body capsules each fired an overlap during a single dash. Gated to a single broadcast so one dash deals damage exactly once.
02
Dash blocked by ground frictionCached original friction and forced it to 0.0f during the dash impulse, restoring it on ability end so the slide reads crisp.
03
Enemies colliding mid-knockbackPushed enemies stalled when they hit each other. Switched their collision channel to Ignore during the push, back to Block on end.
04
Melee combo never resettingAnimNotify-driven reset on three conditions — idle timeout, ability cast, and taking a hit — so the combo counter loops correctly.
05
Sword collided without overlapReplaced query-only physics collision with AnimNotifyState-gated No Collision + overlap, cutting needless ticks and fixing phantom hits.
